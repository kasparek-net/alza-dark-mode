# Alza Dark Mode

Userscript that adds a dark mode to Alza.cz and Alza.sk. It turns on only when the system uses dark appearance.

## Install

Install a userscript manager (Userscripts for Safari, Tampermonkey, Violentmonkey), then open:

https://raw.githubusercontent.com/kasparek-net/alza-dark-mode/main/alza-dark.user.js
